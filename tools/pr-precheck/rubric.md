## Verdict rule

Accept only if all required checks pass. Unclear counts as fail. Preferred checks don't change the verdict. A PR that honestly discloses a shortfall can still be accepted: a deferral or a change the plan didn't name that's recorded in a Deviations note and restated in the description doesn't fail the plan checks. The one exception is Clean diff, where debris and unrelated hunks fail even when disclosed.
